# Configure your project

This Storybook project contains a reusable React component library.

## Available Components

### Button

The Button component supports multiple variants and sizes.

- Primary
- Secondary
- Danger
- Outline
- Disabled

### Input

The Input component supports:

- Label
- Placeholder
- Required state
- Disabled state
- Error message

### Card

The Card component supports:

- Title
- Description
- Content
- Footer

### Modal

The Modal component supports:

- Open and close functionality
- Custom title
- Close button
- Escape key support

## Storybook Components

Use the Storybook sidebar to explore each component.

Select a component story and use the **Controls** panel to change its properties interactively.

For example, the Button component allows you to change:

- Button text
- Variant
- Size
- Disabled state
- Button type

## Component Testing

Each component has different stories that demonstrate its available states and variations.

This makes it easy to review and test reusable components before using them in an application.
